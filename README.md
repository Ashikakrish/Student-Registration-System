# 🎓 Student Registration System

A responsive **Student Registration System** built using **HTML, CSS, JavaScript, Google Apps Script, and Google Sheets**. The application allows students to register through a simple web form, validates user input, and stores the submitted data directly in Google Sheets without requiring a traditional backend.

## 🚀 Features

* Student registration form
* Responsive and modern UI
* Input validation (Email & Phone Number)
* Toast notifications for success and errors
* Loading spinner during submission
* Data stored automatically in Google Sheets
* Google Apps Script integration
* Mobile-friendly design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Google Apps Script
* Google Sheets

## ⚙️ How It Works

1. User fills in the registration form.
2. JavaScript validates the entered data.
3. The form data is sent to Google Apps Script using the Fetch API.
4. Google Apps Script stores the data in Google Sheets.
5. A success message is displayed after successful registration.
